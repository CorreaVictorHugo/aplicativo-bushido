PADRÕES ARQUITETURAIS ADOTADOS
==============================

1. **Server Components por padrão**
   - Pages (page.tsx) são Server Components
   - Data fetching direto no componente (async/await)
   - Client Components apenas quando necessário ('use client')

2. **Client Components isolados**
   - Formulários (CadastroForm, LoginForm) = 'use client'
   - Providers (TanStack Query) = 'use client'
   - Hooks (useSupabase) = 'use client'

3. **Supabase Client por ambiente**
   - `lib/supabase/client.ts` → createBrowserClient (Client Components)
   - `lib/supabase/server.ts` → createServerClient (Server Components, Middleware, Actions)
   - `hooks/useSupabase.ts` → memoizado para evitar múltiplas instâncias

4. **Middleware como Auth Guard**
   - Executa em TODAS as rotas (matcher amplo)
   - Verifica sessão via cookies (@supabase/ssr)
   - Redireciona baseado em autenticação + role (profiles.role)

5. **Validação em duas camadas**
   - Client: Zod + React Hook Form (UX imediata)
   - Server: Database constraints + RLS (segurança real)

6. **Database-First Auth Flow**
   - Trigger `handle_new_user` (security definer) em `auth.users`
   - Cria `profiles` + `students` atomicamente
   - `raw_user_meta_data` transporta dados do signUp para o trigger
   - RLS policies garantem isolamento por usuário

7. **Type Safety End-to-End**
   - `lib/supabase/types.ts` espelha schema do banco
   - Zod schemas inferem tipos TypeScript
   - Supabase client tipado com generics (ex: `supabase.from<Student>('students')`)


FLUXO DE AUTENTICAÇÃO
=====================

CADASTRO (Sign Up)
------------------
1. User preenche form → Zod valida
2. `supabase.auth.signUp({ email, password, options: { data: {...} } })`
3. Supabase Auth cria user em `auth.users`
4. Trigger `handle_new_user` dispara (AFTER INSERT ON auth.users)
   - INSERT em `profiles` (role='student', status='active')
   - INSERT em `students` (dados de raw_user_meta_data)
5. Se sucesso → redirect `/` + refresh

LOGIN (Sign In)
---------------
1. User preenche form → Zod valida
2. `supabase.auth.signInWithPassword({ email, password })`
3. Supabase valida credenciais, cria sessão, seta cookies
4. Middleware intercepta próxima request
   - `supabase.auth.getSession()` lê cookies
   - Busca `profiles.role` para decidir redirect
5. Redirect: admin → `/admin`, student → `/`

MIDDLEWARE PROTECTION
---------------------
- Rotas `/admin/*`: exige session + role='admin'
- Rotas `/login`, `/cadastro`: se autenticado → redirect (admin→/admin, student→/)
- Outras rotas: acesso livre (público) ou protegido por RLS no banco

RLS (ROW LEVEL SECURITY) - PRINCÍPIOS
=====================================

1. **Todas as tabelas têm RLS habilitado**
2. **Políticas por role:**
   - `student`: vê/edita apenas próprios dados (profile_id = auth.uid())
   - `admin`: acesso total (EXISTS profiles WHERE id=auth.uid() AND role='admin')
3. **Triggers de auth** usam `security definer` para bypass RLS na criação
4. **Nunca confie apenas no frontend** — RLS é a barreira real


COMANDOS DE DESENVOLVIMENTO
===========================

npm run dev        # Inicia dev server com Turbopack (http://localhost:3000)
npm run build      # Build produção (typecheck + lint + compile)
npm run lint       # ESLint flat config
npx tsc --noEmit   # Apenas typecheck (rápido)

SUPABASE CLI (opcional)
-----------------------
npx supabase start        # Inicia stack local (Docker)
npx supabase db reset     # Reset + aplica migrations
npx supabase db diff      # Gera nova migration
npx supabase gen types    # Atualiza lib/supabase/types.ts


CONVENÇÕES DE CÓDIGO
====================

- **Português** em: UI strings, mensagens de erro, comentários de arquivo
- **Inglês** em: nomes de variáveis, funções, tipos, componentes, hooks
- **Componentes**: PascalCase (LoginForm.tsx)
- **Hooks**: camelCase com prefixo use (useSupabase.ts)
- **Utils/Schemas**: camelCase (loginSchema.ts)
- **Tipos**: PascalCase + sufixo descritivo (Profile, Student, CheckInStatus)
- **Enums/Constantes**: UPPER_SNAKE_CASE
- **Sem comentários desnecessários** — código auto-explicativo
